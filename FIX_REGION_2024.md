# BazarIQ — исправление HTTP 422 для TOP-5 регионов по году

- Русский запрос о пяти регионах с наибольшим числом сделок за 2024 год теперь обрабатывается детерминированным SQL без Gemini (также распознаёт аналогичный узбекский запрос и другие явно указанные годы).
- Точный фильтр: `deals.day >= '2024-01-01' AND deals.day < '2025-01-01'`.
- Для регионов используется регион сделки `deals.region`, а не адрес регистрации продавца или покупателя.
- Знаменатель доли — все сделки республики за тот же период.
- UZS суммы конвертируются из USD по `usd_rates.rate` на дату сделки. Неизвестная валюта или отсутствующий курс приводят к честному отказу от суммы, не к молчаливому пропуску.
- Результаты сортируются по количеству сделок, затем региону; 5 строк.
- HTTP 422 для других вопросов не устранён автоматически: неверный SQL по-прежнему блокируется валидатором.

## Обновление существующего GitHub/Render

Для этого исправления достаточно заменить в корне GitHub `analyst.py` и `fastpath.py`, сделать Commit changes и Render > Manual Deploy > Deploy latest commit. Части базы заново загружать не надо.

Запуск тестов: `python -m unittest discover -s tests -v`.

Не загружайте `.env` или ключ Gemini в GitHub.
