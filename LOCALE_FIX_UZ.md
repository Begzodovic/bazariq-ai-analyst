# BazarIQ RU/UZ javob tili tuzatildi

Sabab: backend savol matniga qarab tilni qayta taxmin qilgan va Gemini `lang` qiymati tanlangan interfeys tilini bekor qilgan. Endi `lang=ru`/`lang=uz` API so'rovi ustuvor, model uni o'zgartira olmaydi.

O'zgargan: analyst.py, app.py, index.html.

GitHub'da shu uch faylni almashtiring va Render'da eng so'nggi commitni deploy qiling. `uzex.db`ni almashtirmang. Brauzerda Ctrl+F5 bosing.

Sinovlar:
1) RU tanlab, o'zbekcha `Brokerlarning shaxsiy oylik maoshi qancha?` so'rang. Agar ma'lumot bo'lmasa ruscha izoh chiqishi kerak.
2) UZ tanlab, ruscha `Сколько зарабатывают брокеры?` so'rang. Agar ma'lumot bo'lmasa o'zbekcha izoh chiqishi kerak.
3) RU tanlab `Salom` yuboring: ruscha salomlashish chiqishi kerak.

Eslatma: eski chatda SAQLANGAN javob matnlari avtomatik tarjima qilinmaydi; yangidan so'rab tekshiring. Ma'lumot yo'q holati SQL xatoligidan alohida saqlanadi.
